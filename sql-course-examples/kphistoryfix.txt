I have a table of companyid, foid and fyear. I want to group the rows that have the same companyiod, foid, and that have years that are not more than one different than any other fyear in the group. In other words, 2020, 2021 and 2022 should be in a group together, but 2024 should not be in that group.

This problem is commonly known as a Gaps and Islands problem in SQL and Data Analysis. The goal is to detect sequences of contiguous consecutive years for each (companyid, foid) pair and assign a unique group identifier to each continuous island.

Here are solutions in SQL and Pandas (Python).

Method 1: SQL Solution (Standard SQL / Window Functions)
The most robust way to solve this in SQL is by subtracting an incrementing sequence (ROW_NUMBER()) from the fyear. For contiguous years, both numbers increment by 1 at the same rate, making their difference constant. When a gap occurs, the difference changes, creating a distinct group_id.

SQL
WITH RankedData AS (
    SELECT 
        companyid,
        foid,
        fyear,
        -- Subtract row number from fyear to identify contiguous blocks
        fyear - ROW_NUMBER() OVER (
            PARTITION BY companyid, foid 
            ORDER BY fyear
        ) AS grp_offset
    FROM dbo.kphistory
)
SELECT 
    companyid,
    foid,
    fyear,
    -- Generate a clean group ID per continuous block
    DENSE_RANK() OVER (
        PARTITION BY companyid, foid 
        ORDER BY grp_offset
    ) AS group_id
FROM RankedData
ORDER BY companyid, foid, fyear;
How it works step-by-step:
Suppose you have years 2020, 2021, 2022, 2024:

fyear	ROW_NUMBER()	fyear - ROW_NUMBER() (grp_offset)	Resulting Group
2020	1	2019	Group 1
2021	2	2019	Group 1
2022	3	2019	Group 1
2024	4	2020	Group 2
Method 2: Python (Pandas Dataframe)
In Pandas, you can detect gaps where the difference between consecutive sorted years is greater than 1, calculate a cumulative sum to create group markers, and group accordingly:

Python
import pandas as pd

# Sample DataFrame
df = pd.DataFrame(
    {
        "companyid": [1, 1, 1, 1, 2, 2],
        "foid": [10, 10, 10, 10, 20, 20],
        "fyear": [2020, 2021, 2022, 2024, 2018, 2019],
    }
)

# 1. Ensure rows are sorted
df = df.sort_values(["companyid", "foid", "fyear"])

# 2. Identify where fyear gaps are > 1
is_new_group = (
    df.groupby(["companyid", "foid"])["fyear"].diff() > 1
)

# 3. Create group IDs by cumulative sum of gaps
df["group_id"] = (
    df.groupby(["companyid", "foid"]).ngroup().astype(str)
    + "_"
    + is_new_group.cumsum().astype(str)
)

print(df)

In SQL Server, you can generate a globally unique identifier for every continuous group across the entire dataset by using DENSE_RANK() without partitioning by companyid and foid in the outer layer.

Here are two approaches tailored for MS SQL Server: returning all detailed rows with a unique group ID, or returning summary group records.

Option 1: Detailed Rows with Global Unique GroupID
If you want every original row tagged with a global sequential integer GroupID (1, 2, 3, ...):

SQL
WITH GroupedData AS (
    SELECT 
        companyid,
        foid,
        fyear,
        -- Group identifier per (companyid, foid) combination
        fyear - ROW_NUMBER() OVER (
            PARTITION BY companyid, foid 
            ORDER BY fyear
        ) AS grp_offset
    FROM dbo.kphistory
)
SELECT 
    companyid,
    foid,
    fyear,
    -- Generates a unique integer ID across the entire table
    DENSE_RANK() OVER (
        ORDER BY companyid, foid, grp_offset
    ) AS GroupID
FROM GroupedData
ORDER BY GroupID, fyear;

To select the row with the maximum fyear in each group in SQL Server, you can extend the Common Table Expression (CTE) using ROW_NUMBER() ordered by fyear DESC within each group, or simply group by the calculated island key and select MAX(fyear).

Option 1: Simple Aggregation (GROUP BY)
If your original table only contains companyid, foid, and fyear (or if you only need these columns), group by the island offset key directly:

Option 2: ROW_NUMBER() DESC (Best if you have extra columns)
If your table has other columns (e.g., amount, status, created_date) and you want to retrieve the complete row corresponding to the maximum fyear of each island group:

SQL
WITH GroupedData AS (
    SELECT 
        *,
        fyear - ROW_NUMBER() OVER (
            PARTITION BY companyid, foid 
            ORDER BY fyear
        ) AS grp_offset
    FROM dbo.kphistory
),
RankedInGroup AS (
    SELECT 
        *,
        DENSE_RANK() OVER (ORDER BY companyid, foid, grp_offset) AS GroupID,
        ROW_NUMBER() OVER (
            PARTITION BY companyid, foid, grp_offset 
            ORDER BY fyear DESC
        ) AS rn
    FROM GroupedData
)
SELECT 
    companyid,
    foid,
    fyear,
    GroupID
    -- Select any other original columns here
FROM RankedInGroup
WHERE rn = 1
ORDER BY GroupID;

To perform an UPDATE in SQL Server on a subset of rows identified using Common Table Expressions (CTEs) and window functions, you can run an UPDATE directly against the CTE. SQL Server allows updating CTEs as long as the underlying target table rows are deterministically referenced.

MS SQL Server UPDATE Statement
SQL
WITH GroupedData AS (
    SELECT 
        companyid,
        foid,
        fyear,
        active,
        deleted,
        -- Identify continuous gaps and islands
        fyear - ROW_NUMBER() OVER (
            PARTITION BY companyid, foid 
            ORDER BY fyear
        ) AS grp_offset
    FROM dbo.kphistory
),
RankedInGroup AS (
    SELECT 
        companyid,
        foid,
        fyear,
        active,
        deleted,
        -- Identify the row with the maximum fyear in each group
        ROW_NUMBER() OVER (
            PARTITION BY companyid, foid, grp_offset 
            ORDER BY fyear DESC
        ) AS rn
    FROM GroupedData
)
UPDATE RankedInGroup
SET deleted = 1
WHERE rn = 1           -- Row with maximum fyear in the group
  AND active = 0;      -- Condition: active value is 0
How It Works
GroupedData CTE: Uses fyear - ROW_NUMBER() to assign the continuous group identifier (grp_offset) to every row.

RankedInGroup CTE: Ranks the rows within each island group by fyear DESC so that rn = 1 represents the latest fyear in that continuous group.

UPDATE statement: Targets RankedInGroup directly, filtering for rn = 1 and active = 0, updating the deleted column in the underlying base table to 1.

Option 1: Returning Single-Row Groups with Single Rows
This query retrieves the exact rows that belong to single-fyear groups along with their global group identifier:

SQL
WITH GroupedData AS (
    SELECT 
        companyid,
        foid,
        fyear,
        -- Group identifier per (companyid, foid) continuous sequence
        fyear - ROW_NUMBER() OVER (
            PARTITION BY companyid, foid 
            ORDER BY fyear
        ) AS grp_offset
    FROM dbo.kphistory
),
GroupCounts AS (
    SELECT 
        companyid,
        foid,
        grp_offset,
        COUNT(*) AS group_size,
        DENSE_RANK() OVER (ORDER BY companyid, foid, grp_offset) AS GroupID
    FROM GroupedData
    GROUP BY companyid, foid, grp_offset
    HAVING COUNT(*) = 1
)
SELECT 
    g.companyid,
    g.foid,
    g.fyear,
    gc.GroupID
FROM GroupedData g
JOIN GroupCounts gc 
    ON g.companyid = gc.companyid 
   AND g.grp_offset = gc.grp_offset
ORDER BY gc.GroupID;
